VIRTUAL HIDE & SEEK — WEBSITE FILES

Isi folder:
- index.html: halaman game.

Cara mempublikasikan dengan GitHub Pages:
1. Masuk ke https://github.com dan buat repository baru bernama virtual-hide-seek.
2. Pilih repository tersebut, lalu pilih Add file > Upload files.
3. Upload index.html dari folder ini, lalu commit.
4. Buka Settings > Pages.
5. Pada bagian Build and deployment, pilih Deploy from a branch.
6. Pilih branch main dan folder /(root), lalu Save.
7. Tunggu proses publikasi selesai. GitHub akan menampilkan alamat website HTTPS.

Catatan:
- File ini memakai Leaflet dari CDN dan tile OpenStreetMap, jadi pengunjung perlu internet.
- Tetap tampilkan atribusi OpenStreetMap di peta.
- Layer satelit, Street View, dan multiplayer belum tersedia di prototype ini.
- Jangan mengunduh tile peta secara massal atau membuat cache/offline tile dari server standar OpenStreetMap.
